# SoDEX Reports

Purpose: generated or dated SoDEX outputs from farming audits, monitor evals, wallet audits, and research cycles.

Use this folder for:

- dated SoDEX audit reports;
- farming and monitor evaluation reports;
- quant-stat and TA gate outputs;
- HTML/PDF report artifacts.

Do not use this folder for:

- wallet private data;
- live logs;
- raw market data;
- source code.

Current SoDEX reports still live in `docs/` and `reports/` root until references are checked.
