2. Temuan A1 — Denominator fail-open (BUG NYATA, DIPERBAIKI)

Kelas bug: sama dengan kelas rc=0, orderID=0 (Rule 7 riset-penelitian: harness wajib fail-closed).

Mekanisme: 1. sodex_realtime_sync.py menulis spot_equity_usd hanya bila mark harga spot berhasil. 2. Snapshot 2026-10-25 07:48Z: spot_mark_error = "HTTP 429 Too Many Requests" → kunci spot_equity_usd tidak ada. 3. sodex_maturation_tracker._read_live_wallet() membaca spot_equity_usd or 0 → spot = 0. 4. Guard spot + perps >= 20 lolos karena perps = $184,97 → wallet dilaporkan $184,97 padahal wallet sebenarnya $243,02 (spot vUSDC $49,28 + posisi spot kecil + perps). 5. Semua metrik % (window mean/median/hit, target 0,8%) dihitung di denominator yang terlalu kecil → ter-inflasi 31,4%.

Dampak terukur:

Denominator Target 0,8% PnL $1,48 terbaca Status gate
$184,97 (bug) $1,48 0,80% LOLOS (palsu)
$243,02 (benar) $1,94 0,61% GAGAL

Fix (surgical, sudah diterapkan): - Fallback spot_vusdc.total bila spot_equity_usd absen. - Label eksplisit +SPOT_UNMARKED(lower-bound) pada wallet_source bila spot_mark_error ada, sehingga denominasi lower-bound tidak pernah lagi dipakai diam-diam. - Verifikasi sesudah fix: tracker 07:50Z → $243,02 [onchain_snapshot@10-25 07:50Z].

Catatan penting: angka $262,77 pada status 01:25Z bukan bug — snapshot saat itu punya mark spot lengkap; wallet memang bergerak $262,77 → $243,02 dalam ~6 jam (spot vUSDC berubah). Bug hanya terjadi pada jendela ketika mark gagal.

3. Temuan A2 — Kriteria #5 (t≥3,80 pada M5) invarian terhadap denominator

M5 = (M1_window − M2_window)/wallet per window. Pembagi sama untuk semua window → statistik t dari uji berpasangan tidak berubah oleh skala denominator (t = mean(d)/sd(d)·√n). Artinya:

  • Kriteria #5 tidak terpengaruh bug A1.
  • Kriteria #2 (M1 ≥ 0,8%), #3 (median M3 > 0), #4 (hit ≥ 50%) terpengaruh karena absolut.

Kesimpulan metodologis: laporan yang hanya menyajikan t tanpa level % absolut bisa lolos meski denominator salah — karena itu audit level-per-level (Rule 8) wajib.

7. Batas audit ini

  1. Audit mereproduksi aturan, bukan menilai kualitas ekonomi mesin. Mesin yang net negatif tetap net negatif.
  2. Denominator bergerak mengikuti wallet live; angka % historis berubah bila wallet berubah (properti definisi "total modal", bukan bug). Yang diperbaiki hanyalah fail-open saat mark gagal.
  3. Tidak ada trade baru yang dihasilkan audit; semua angka berasal dari state paper yang ada.
  4. Window dihitung dari exit_ts (konvensi tracker & protokol); konvensi entry tidak diuji ulang di sini.
