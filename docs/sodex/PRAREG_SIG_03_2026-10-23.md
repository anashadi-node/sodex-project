## 3. Definisi sinyal (dibekukan — tidak ada tuning)

- `r_L(t) = c(t) / c(t-L) − 1`, dengan **L = 7** bar harian.
- Universe pada tanggal t: simbol dengan (a) ≥ 60 bar riwayat, (b) data pada t dan t−7, (c) **top 50** berdasarkan median `qav` 30 hari terakhir (filter likuiditas, rolling, tanpa lookahead).
- Peringkat cross-sectional `r_L(t)` di dalam universe.
- **Long** kuintil teratas (20%), **short** kuintil terbawah (20%), **equal weight**, dollar-neutral.
- Bobot: long +0,5 total, short −0,5 total → gross 1,0, net 0.

## 4. Konstruksi portofolio (dibekukan)

- **Formasi harian, holding H = 7 hari** (portofolio overlapping): return portofolio pada hari t+1 = rata-rata sederhana dari portofolio yang dibentuk pada t−6 … t.
- Return harian = 0,5 · mean(r_long) − 0,5 · mean(r_short), dengan r = close-to-close.
- **Biaya:** taker **10 bps per round trip per leg** (asumsi konservatif Binance USDⓈ-M). Biaya harian = 10 bps × |Δbobot| (turnover harian), dihitung dari perubahan bobot agregat; tidak ada asumsi maker fill.
- Tidak ada leverage tambahan, tidak ada slippage terpisah (sudah tercakup dalam asumsi taker konservatif).

## 6. Kriteria lulus (semua wajib, dibekukan sebelum eksekusi)

| # | Kriteria | Ambang |
|---|---|---|
| K1 | Mean net OOS | **> 0** dan **≥ 9,57 bps/hari-ekuivalen** (ambang gross proyek) |
| K2 | Inferensi | **t HAC (Newey–West, lag = 7) ≥ 2,5** (ambang internal: t<2,5 tidak diputuskan) |
| K3 | CI95 bootstrap blok (10.000 resample, blok 4 minggu) | **lower bound > 0** |
| K4 | Kontrol acak (200 portofolio peringkat acak, seed 42) | strategi harus **> persentil 95** distribusi kontrol |
| K5 | Kontrol drift/beta | return strategi harus melebihi benchmark long-only universe yang sama (beta-matched) — alpha sisa > 0 |
| K6 | Kontrol lookahead (shift sinyal +1 hari) | return ≈ 0; jika positif signifikan → ada kebocoran, hasil utama **dibatalkan** |
| K7 | Konsistensi sub-periode OOS (2024, 2025, 2026) | tanda positif di **≥ 2 dari 3** tahun |

**Gagal satu kriteria = DITOLAK.** Tidak ada "hampir lulus".

## 7. Kekuatan uji (dinyatakan jujur sebelum jalan)

Dengan n ≈ 1.010 hari OOS dan σ harian portofolio ≈ 0,6–0,8%, MDE (80% power, α=0,05 dua sisi) ≈ **5–7 bps/hari ≈ 35–50 bps/minggu**. Artinya:
- Hasil **positif** dengan t ≥ 2,5 = edge nyata dan cukup besar.
- Hasil **null** TIDAK membuktikan tidak ada edge kecil (< 35 bps/minggu). Namun edge di bawah ambang itu tidak bisa menutup biaya + target, jadi keputusan operasionalnya tetap sama: tidak dialokasikan.

## 8. Yang TIDAK diuji di sini

- Eksekusi live, slippage venue nyata, kapasitas, short-borrow di spot.
- Target 0,8%/30 jam — horizon 7 hari tidak relevan untuk window itu.
- Kombinasi dengan sinyal lain, regime switching, atau exit intraday.
