7. Semua Permasalahan — 17 Masalah

A. FUNDAMENTAL

  1. Tidak Ada Edge Profit — backtest membuktikan directional scalp tidak memiliki edge statistik
  2. Pair Illiquid — PEPE/SHIB/AVAX spot tidak memiliki natural taker flow
  3. Fee Floor Matematis — rasio maksimum 1:9,259 single-leg, tidak bisa lebih tinggi tanpa naik tier
  4. Farming = Airdrop Strategy, Bukan Profit Strategy — nilai ada pada SoPoints, bukan PnL

B. TEKNIS

  1. Post-Maintenance API Changes — GTC limit BUY diblokir (oid=0), cancel butuh --symbol-id numerik
  2. AVAX Quantity Invalid — semua order quantity ditolak, tick/lot size berubah
  3. PEPE Book Fetch Failure — orderbook return empty {} setelah runtime tertentu
  4. SCALP_MODE Boolean Bug — '11'=='1' = False, gate salah membaca mode multi-digit
  5. CLI bin/sodex SPOF — semua operasi bergantung satu binary
  6. Telegram Bot 401 — token mungkin expired

C. OPERASIONAL

  1. Systemd Restart Loop — daemon restart setiap ~90 detik
  2. Ghost Positions — SPCX-USD dan 1000PEPE-USD muncul kembali setelah ditutup
  3. Watchdog Zombie — watchdog_twin.sh respawn setelah di-kill
  4. Multiple Daemon Instances — systemd + nohup = conflict

D. DESAIN

  1. Pure Maker Deadlock — di pair illiquid, SELL tidak fill → inventory terkunci
  2. Market Order = Rugi Spread — setiap RT bayar 0.3-0.7%
  3. Hedge vs BEARDOWN Konflik — hedge buka posisi perps yang blokir BEARDOWN
