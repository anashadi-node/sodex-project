2.2 Cara Kerja — Dynamic Two-Sided Quote

╔══════════════════════════════════════════════════════════╗ ║ E1 SPOT MAKER — _place_two_sided() ║ ╠══════════════════════════════════════════════════════════╣ ║ ║ ║ 1. ANALISIS SPREAD ║ ║ ├─ Baca orderbook (depth=3) ║ ║ ├─ Hitung spread = (ask-bid)/bid ║ ║ └─ Gate: spread > min_spread? → lanjut ║ ║ ║ ║ 2. PLACE TWO-SIDED QUOTE (BERSAMAAN) ║ ║ ├─ BUY @ bid (maker, gtc) ║ ║ └─ SELL @ ask (maker, gtc) ║ ║ ║ ║ 3. DYNAMIC RE-QUOTE (setiap tick / 5-10 detik) ║ ║ ├─ Cek apakah harga bergerak > threshold? ║ ║ ├─ Jika YA → cancel order lama → place baru ║ ║ └─ Jika TIDAK → biarkan order jalan ║ ║ ║ ║ 4. FILL DETECTION ║ ║ ├─ BUY filled? → dapat token → siap SELL ║ ║ ├─ SELL filled? → dapat USDC → siap BUY ║ ║ └─ Both filled? → ROUND TRIP COMPLETE ✅ ║ ║ ║ ║ 5. REGIME-AWARE ADAPTATION ║ ║ ├─ BEAR → SELL-ONLY (jangan akumulasi inventory) ║ ║ ├─ BULL → BUY-ONLY (akumulasi untuk jual mahal) ║ ║ └─ SIDEWAYS → TWO-SIDED (normal spread capture) ║ ║ ║ ║ 6. INVENTORY SKEW MANAGEMENT ║ ║ ├─ Inventory > max? → hanya SELL (kurangi) ║ ║ ├─ Inventory < min? → hanya BUY (tambah) ║ ║ └─ Balanced? → TWO-SIDED ║ ║ ║ ╚══════════════════════════════════════════════════════════╝

⚠️ 2.6 Kenapa Engine Ini Dimatikan?

BUKAN karena engine-nya rusak. Engine ini BAGUS dan TERBUKTI.

Penyebab: Pada 26 Juni 2026, ditemukan bahwa SELL spot DIBLOKIR di level akun SoDEX (no-withdraw flag). 15/15 SELL spot gagal dengan oid=0. BUY selalu OK. Perps buy+sell OK.

Karena SELL tidak bisa, engine tidak bisa menyelesaikan round-trip → inventory PEPE nyangkut → engine dimatikan (TE_E1_ENABLED=0).

Ini BUKAN masalah kode. Ini masalah akun. Begitu SELL block di-resolve, engine ini bisa langsung di-re-enable.
